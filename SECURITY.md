# Security Policy

Supported version: latest published release. This is an early-stage static scanner, not a substitute for sandboxing or security review.

**Private vulnerability reports:** use GitHub's **Report a vulnerability** feature under this repository's Security tab (if enabled). Otherwise contact the maintainer privately through GitHub before sharing details. Do not open a public issue containing exploit details or credentials. Include a minimal safe reproduction, tested platform and version.

Never assume that an empty ClonePeek report means a repository is safe. See [threat model](docs/THREAT_MODEL.md) for explicit limitations.
